布局逻辑

  • 竖屏 = 上视频 + 下内容两段；内容区整片可滚，滚动不触发视频区手势（各管各）
  • 内容区不再是悬浮抽屉：无暗区、无关闭按钮，常显在视频下方
  • 播放控制全部回归视频浮层（点按唤出，3s 自隐）+ 手势，与主流竖屏播放器一致
  • 竖屏右上角 ⋯ 按钮移除（内容已平铺，避免一个功能两个入口）；横屏保留 ⋯ 右侧抽屉现状
  • 竖屏进横屏：浮层右下新增 ⛶ 全屏小钮（26dp）+ 重力感应自动旋转，双通道

与 MorePanel 的关系

  • 区段、顺序、文案、chip 样式（圆角 10 / 底色 0x24FFFFFF / 选中 AccentBlue）全部 1:1 复用，视觉零新造
  • 实现上把 MorePanel 的各区段抽成共用 composable，竖屏平铺与横屏抽屉调同一套
  • 打开内容区即自动扫投屏设备（沿用「不用再点一次」的既有行为）

边界情形

  • 电影：按需求⑨不渲染选集区，其余区段照常
  • 直播（电视页）：下方仍是现有「信号源」横滑条，不套用本设计
  • 选集 ≥20 集：10 集/页分页 chip；<20 集全量展示（EpisodeMenuPolicy 口径不变）
  • 剧集标题带「第N集」，电影只显示片名

纯字形规格

  • 无底、无边框：不加任何底色/胶囊/毛玻璃
  • 字形：双三角 40dp 纯白，快退为左右镜像；整体投影 0 3px 10px rgba(0,0,0,.6)
  • 时间：14sp SemiBold 等宽数字，位于字形下方 8dp，同投影
  • 位置与动画不变：双击侧 1/4 居中，700ms 自隐；连续双击只更新时间与方向
  • 直播态时间位置显示「直播」不变

三类手势浮层语言

  • 单击滑动类（亮度 / 音量 / 横滑进度）：保持现有毛玻璃胶囊，仅补图标（见下示意）
  • 双击快进退：无底色纯字形（本稿定稿）——瞬时反馈不给画面加盖任何东西
