# My TV 自建服务器与 CloudBase 退役设计

日期：2026-09-24  
状态：已由用户批准（2026-09-24）
依据：桌面方案《MyTV-新云服务器全链路性能优化方案-彻底去CloudBase版-2026-09-24.md》、既有《2026-09-23-cloudbase-self-hosted-migration-design.md》及本轮用户补充的旧 APK 范围。

## 1. 目标与范围

将当前受支持的 My TV 生产路径统一到自建服务器，最终使 TV APK、移动 APK、网页版、后台和发布流程都不依赖 CloudBase。用户明确已发布的旧 APK 不纳入本轮兼容或强制升级范围。

本设计覆盖自建服务器网络/容量、域名/TLS、对象 Range、当前代码与部署配置中的 CloudBase 路径、以及 TV/移动/Web 当前交付物的自建端到端验收。

本设计覆盖并取代 2026-09-23 迁移设计中“CloudBase 兼容旧客户端至 2026-10-09”的要求。旧版兼容代理、强制升级、对象镜像和旧版流量观察均不再是本轮成功条件。历史记录可保留，但必须标为已退役，不能继续作为当前操作说明。

## 2. 已核实现状

- 当前产品矩阵为 TV APK、移动 APK、Web。
- 本轮只读检查中，自建 HTTPS 健康接口与 metadata 健康接口均返回 200；metadata 返回 schema 3、FTS5 可用。公网健康响应不证明 VPS 能访问片源 API。
- 当前自建入口使用 IP 与迁移 CA；仓库尚未确认正式域名、公共证书和续期配置。
- 项目文档记录 VPS 片源 API 出网曾不可用，片源静态索引由家宽构建；健康接口不能代替 VPS 出口测试。
- 部分自建配置已关闭 CloudBase relay/点播兜底，但生产代码与发布脚本仍保留 CloudBase 路径。
- 既有迁移规格记录目标机为 Ubuntu Server 24.04.1、约 4 GB RAM、29 GB 系统盘及 NAT 端口映射；必须重新登录实测后才能视为当前容量事实。

## 3. 目标结构

当前支持客户端、Web 和后台只通过经验证的自建 HTTPS 入口调用业务、metadata、VOD、IPTV、激活、热更新和对象服务。客户端优先直连媒体源；服务器不作为默认视频中继。

当前版本授权功能须完整保留，包括卸载重装后的同设备恢复：只返回已绑定到该设备、仍有效且未封禁的既有授权，不得新增设备位、改变激活时间或延长有效期。旧 APK 兼容虽排除在外，不能据此删除当前 APK 的授权行为。

CloudBase 不再提供当前版本的 API、relay、静态索引兜底、对象镜像、管理入口、热更新或部署能力。旧 APK 可能仍保留编译时地址，但不属于本轮维护承诺。

## 4. 实施阶段与门槛

### 阶段 0：服务器网络与容量验收

从目标 VPS 本机测试当前后台启用的源 API：DNS、TCP、TLS、列表/搜索、详情和播放地址解析；抽测视频 CDN、HLS manifest 与首个分片。记录各阶段耗时、状态码、IPv4/IPv6 和重定向。探测须遵守源站频率限制，不绕过反爬、鉴权或访问控制。

来源 API 出口未达标时，不切换动态回源，也不把该 VPS 当作 CloudBase 的功能等价替代。可以继续验证静态索引与客户端直连路径，但动态回源门槛保持未通过。

### 阶段 1：域名、HTTPS 与自建服务

使用实际正式域名验证 DNS、公共 CA 证书、自动续期、HTTPS 路由和浏览器信任。没有域名时，IP 加迁移 CA 只作为测试入口，不满足生产验收。验证服务重启恢复、PostgreSQL 备份、对象 Range/ETag、磁盘空间和内存峰值。

### 阶段 2：当前生产路径清理

审计并移除当前生产代码和部署中的 CloudBase 地址、环境变量、兼容 relay、回退分支、对象镜像、管理入口和发布行为。release/deploy 流程只操作自建环境，不调用 CloudBase CLI/API。仅历史文档与变更记录可保留带“已退役”标记的审计内容。

### 阶段 3：验证与退役

完成 TV APK、移动 APK、Web 与后台功能矩阵后，验证当前版本运行时没有 CloudBase 请求。发布后核对线上页面/包与本地产物哈希。旧 APK 可用性不计入验收。

## 5. 回滚与安全

代码回滚使用已验证的 Git 提交和旧自建容器镜像。服务器数据回滚使用异机备份和对象校验清单；切换前确认自建环境可恢复。CloudBase 不作为本轮默认回滚目标。

私钥、卡密、Cookie 和服务密钥不得写入 Git、镜像、普通日志或文档。

## 6. 验收条件

- 从目标 VPS 完成源 API 出口测试；无服务器侧证据时此项保持未通过。
- 正式域名和公共证书有效；迁移 CA/IP 仅供测试。
- health、激活、热更新、IPTV、Web、metadata、VOD resolve、Range 下载均通过当前入口验收。
- 当前 APK 同设备授权恢复通过自建 API 与 PostgreSQL 合同验收；失败恢复不能创建绑定、增加设备位或改变有效期。
- 数据库备份可恢复；对象数量、大小和 SHA-256 抽检一致。
- 当前 TV APK、移动 APK、Web、后台与发布流程无可运行的 CloudBase 生产路径。
- 当前支持版本运行时 CloudBase 请求为零。
- 整体性能与客户端验收门槛见配套 Resolver、Android 和 Web 规格。

## 7. 外部条件

生产出网验收需要目标机只读 shell 访问方式；正式 HTTPS 验收需要实际域名及 DNS 控制权。仓库当前未确认可用的 VPS SSH alias 或正式域名。不得用本地电脑访问源站的结果代替 VPS 出网证据。
